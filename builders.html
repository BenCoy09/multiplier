For builders.

Most apps treat Robinhood Chain stock tokens like ordinary ERC-20s. This is the exact place that breaks, how to read them correctly, and an open API you can call instead of rebuilding it.

The one idea. A stock token’s balance can stay the same while the real shares it stands for change, because a multiplier changes. Real shares = raw balance × multiplier ÷ 1e18.

What to read

  • Raw amount: the value in Transfer events. We reconcile balanceOf against transfer history and treat it as raw.
  • Scaled amount: TransferWithScaledUI also carries uiValue, which equals raw × multiplier. Both events are emitted for one transfer, so never add them together.
  • Multiplier changes: the UIMultiplierUpdated event. It carries the time the change takes effect, which is later than when the event is emitted (about ten minutes in both updates we checked). Use the effective time.

Four ways it goes wrong

  • Floating point. Multipliers have 18 decimals. JavaScript Number silently loses precision. Use BigInt.
  • Emit time versus effective time. Applying a change when the event appears is wrong. Wait for effectiveAt.
  • Double counting. Summing Transfer and TransferWithScaledUI counts every transfer twice.
  • Prices. As we read Robinhood’s stock-token docs, the oracle price already includes the multiplier. Applying it again double counts. Check the docs for the feed you use.

Copy-paste patterns

Real shares, exactly:

const shares = raw * newMultiplier / 10n ** 18n;      // BigInt, never Number
const change = raw * (newMultiplier - oldMultiplier) / 10n ** 18n;

Read every multiplier update with plain JSON-RPC:

const TOPIC = "0x2205df4534432b2f60654a3fdb48737ffdaf3e9edb1a498bd985bc026b15b055";
const logs = await rpc("eth_getLogs", [{ address: TOKEN, topics: [TOPIC], fromBlock: "0x0", toBlock: "latest" }]);
const [oldM, newM, effectiveAt] = [0, 1, 2].map((i) =>
  BigInt("0x" + logs[0].data.slice(2 + 64 * i, 66 + 64 * i)));   // effectiveAt is a unix time in seconds

Public RPCs limit eth_getLogs ranges and rates, so be ready to split the range and retry. This tool does that for you.

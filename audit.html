Multiplier audit.

Every multiplier update on record for a stock token, each linked to its transaction on Robinhood Chain. Read from chain events, so you can check any line yourself.

Reading the chain…

How to read this

  • A stock token's balance can stay the same while the real shares it stands for change, because a multiplier changes. Real shares = token balance × multiplier ÷ 1e18.
  • Updates come from the on-chain UIMultiplierUpdated event. The effective time is later than the block that emitted it, so the time shown is the effective time.
  • If the history scan did not finish, this page says so. A token with no update on record has not been re-based in the history we read.

This is a read-only report of on-chain events. No money, no promise of return, and not financial advice.

A token balance doesn’t tell the whole story.

01

A wallet holds tokens

The balance is a raw token amount. A multiplier update does not change it.

02

The multiplier changes

An on-chain event records the old value, the new value and when it takes effect.

03

We work out the difference

Tokens × multiplier, before and after, using the wallet’s balance when the update took effect.

Look up a wallet. See the change.

Choose a stock token and enter a wallet address. Every update links to its transaction, and anything that can’t be verified is stated.

Data is read live from Robinhood Chain through this server. Shares represented = token balance × multiplier. Historical balances are rebuilt from transfer logs up to the last block at or before the update’s effective time. Anyone opening a shared link can see the wallet address in it.
